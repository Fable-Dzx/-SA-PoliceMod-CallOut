# -SA-PoliceMod-CallOut

**This is a simple mod for Grand Theft Auto San Andreas**

Are you play **PoliceMod**?

In PoliceMod we can just **Follow scheduling arrangements**
but can we choose *Police Situation* that we like?

So I made this mod. You should just put the **Callout.cs** to the CLEO Folder 

And press **I**, Then you can choose the *Police Situation* you like!
